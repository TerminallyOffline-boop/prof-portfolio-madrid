# Madrid — JI Telecom Portfolio

A focused portfolio for Madrid James Bernard A., highlighting current JI Telecom work:

- Contributions to [JITelecom.store](https://jitelecom.store)
- [JI Product Adviser](https://github.com/TerminallyOffline-boop/ji-product-adviser), an Android product-selection and compatibility tool
- Graphics design and digital advertising for retail campaigns

The site is deployed from `main` with GitHub Pages. After the first successful deployment, it is available at:

`https://terminallyoffline-boop.github.io/prof-portfolio-madrid/`

## Local preview

Open `index.html` in a browser, or serve the folder with any static-file server.

## Updating the portfolio

Edit `index.html` for content and `styles.css` for the design. Push changes to `main`; the Pages workflow publishes the site automatically.
